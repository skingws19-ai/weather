## 사용자 코드

로그인 화면이 없습니다. 접속하면 **바로 조회**되고, 입력하려면 상단에 코드를 넣습니다.

| 코드 | 결과 |
|---|---|
| `admin` | 전 거점 입력·수정 + 폭염현황 확정 |
| (미입력) | 조회 전용 |

- 코드가 맞으면 상단 표시가 `조회 전용` → `입력 가능` 으로 바뀌고 입력칸이 열립니다.
- `잠금` 을 누르면 다시 조회 전용으로 돌아갑니다.
- 브라우저 탭을 닫으면 해제가 풀립니다. (세션 단위)
- 코드는 `index.html` 의 `const EDIT_CODE='admin';` 한 줄입니다.

> 코드가 소스에 평문으로 들어 있어, 소스를 볼 수 있는 사람은 확인할 수 있습니다.
> 사내 구분용으로는 충분하지만 실제 통제가 필요하면 서버 인증이 필요합니다.

|---|---|
| **계열** | 군산 · 장항 · 대전 · 천안 · 신탄진 · 부산신항 |

그룹 머리에 개소 수와 특보 발효 거점 수가 함께 표시됩니다.

## 입력 방법

칸을 클릭하면 **팝업 없이 그 자리에서** 입력창이 열립니다.

| 키 | 동작 |
|---|---|
| `Enter` | 저장 |
| `Shift + Enter` | 줄바꿈 |
| `Esc` | 취소 |
| 다른 곳 클릭 | 저장 |

저장하면 즉시 공용 저장소로 올라가 다른 PC에 20초 안에 반영됩니다.

## 폭염현황 확정

`✔ 폭염현황 확정` 을 누르면 그 시점의 기상현황·체감온도·폭염특보·입력내용 전체가
스냅샷으로 저장됩니다. **덮어쓰지 않고 계속 쌓입니다.**
하단 `확정 이력` 에서 저장시점·확정자와 함께 조회하고 `보기` 로 상세를 확인합니다.

## 자동 동작

- **새로고침** — 로그인 없이 접속 즉시 1회, 이후 10분마다 자동
- **자정** — 전날 자료를 공용 저장소에 남기고 새 날짜 표를 빈 상태로 준비
- **폭염특보** — 통보문 발효시각(`t5`)이 지난 것만 반영, 발효 예정분은 요약에 별도 안내

## ⚠ Firebase 보안규칙 (먼저 적용)

`FIREBASE_RULES.txt` 내용을 Firebase 콘솔 → Realtime Database → 규칙 에 붙여넣고 게시하세요.

```json
{
  "rules": {
    "days":      { ".read": true, ".write": true },
    "logs":      { ".read": true, ".write": true },
    "confirmed": { ".read": true, ".write": true }
  }
}
```
