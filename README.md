## 확정 저장

### 수동 — `✔ 폭염현황 확정`

그 시점의 기상현황·체감온도·폭염특보·입력내용 전체를 스냅샷으로 저장합니다.
**입력란의 값은 그대로 유지됩니다.** 몇 번을 눌러도 이력에 쌓이기만 합니다.

입력창을 열어둔 채로 확정을 눌러도 그 값이 먼저 저장된 뒤 스냅샷에 담깁니다.

### 자동 — 매일 한국시간 00:00

자정이 지나면 **전일자** 자료를 확정 스냅샷으로 남기고, **그 전일자의 입력란만** 비웁니다.
오늘 입력 중인 값은 절대 건드리지 않습니다.

- 확정자는 `자동(00시)` 로 기록됩니다.
- 자정에 아무도 화면을 켜두지 않았어도, 다음 접속 때 **최근 7일 중 밀린 날짜를 모두** 찾아 처리합니다.
- 여러 PC가 켜져 있어도 하루 한 번만 저장되도록 `/autofix/{날짜}` 에 표식을 먼저 남깁니다.
- 30초 주기로 감시합니다.
- **모든 날짜·시각 판단은 한국시간(KST) 고정**입니다. PC 시간대가 달라도 자정 기준이 어긋나지 않습니다.

> 이전 버전에서는 전일자 **목록만** 받아오고 내용은 읽지 않아,
> 새 브라우저로 접속하면 "저장할 내용이 없다"고 보고 조용히 건너뛰었습니다.
> 지금은 대상 일자의 내용을 공용 저장소에서 직접 읽어온 뒤 판단합니다.

### 이력 조회 · 삭제

`확정 이력` 에서 `보기` 를 누르면 **전 거점이 표로** 펼쳐집니다.
(기상·기온·체감·폭염특보·근로자·제품(시설)·운송 + 기타사항)

잘못 저장된 기록은 **사용자 코드 입력 상태에서 `삭제`** 로 지울 수 있습니다.
조회 전용에서는 삭제 버튼이 보이지 않고 우회 호출도 막힙니다. 삭제는 로그에 남습니다.

## 입력 방법

칸을 클릭하면 팝업 없이 그 자리에서 입력창이 열립니다.
`Enter` 저장 · `Shift+Enter` 줄바꿈 · `Esc` 취소 · 다른 곳 클릭 시 저장.

### 일괄 입력 · 일괄 삭제

거점 패널 제목 옆 두 버튼으로 30칸을 한 번에 처리합니다. (사용자 코드 입력 상태에서만 표시)

| 버튼 | 동작 |
|---|---|
| **전체입력 (특이사항 없음)** | 전 거점의 근로자 · 제품(시설) · 운송 칸을 `특이사항 없음` 으로 채움 |
| **전체삭제** | 전 거점 입력 내용 + **기타사항까지** 모두 지움 |

- 실행 전 확인창이 뜨고, 이미 입력된 거점이 몇 개인지 알려줍니다.
- **기타사항은 전체입력 대상이 아닙니다.** 성격이 달라 일괄로 채우지 않습니다.
- 두 버튼 모두 복사 이미지에는 찍히지 않습니다.
- 실행 내역은 로그에 남습니다.

## ⚠ Firebase 보안규칙

`autofix` 경로가 추가되었습니다.

```json
{
  "rules": {
    "days":      { ".read": true, ".write": true },
    "logs":      { ".read": true, ".write": true },
    "confirmed": { ".read": true, ".write": true },
    "autofix":   { ".read": true, ".write": true }
  }
}
```

`autofix` 가 없어도 자동확정은 동작하지만, 브라우저별로 각각 저장돼 중복될 수 있습니다.

## 새로고침이 안 되는 것처럼 보일 때

두 가지를 정리했습니다.

**① 캐시 제거** — 중계함수가 응답을 5분간 CDN에 캐시하고 있었습니다(`s-maxage=300`).
그 사이에는 새로고침을 눌러도 같은 응답이 돌아왔습니다. 이제 캐시를 완전히 끄고,
호출마다 `_t=타임스탬프` 를 붙여 중간 캐시를 우회합니다.

**② 관측시각을 함께 표시** — 초단기실황은 **매시 정시 관측이 약 40분 뒤 공개**됩니다.
즉 17:45 와 18:20 에 새로고침하면 둘 다 `17:00 관측값`이 나오는 게 정상입니다.
이게 "갱신이 안 된다"로 보이던 부분이라, 관측시각과 갱신시각을 나눠서 보여줍니다.

```
기상청 관측 17:00 · 갱신 18:20
```

관측시각이 그대로면 아직 새 관측이 공개되지 않은 것이고,
갱신시각이 바뀌면 조회는 정상적으로 이뤄진 것입니다.

### 천안 — 수정 내역

`62, 108` → **`63, 108`**

광덕면사무소를 기준으로 잡았는데, 실제 사업장(광덕면 행정리 40-1)은 **동쪽으로 4.5km** 떨어져
격자가 달랐습니다. 잘못된 격자에서는 광덕산 서쪽 산간 기온을 보고 있었습니다.

### 신탄진 CY — 주소 정정

`신일서로126번길 60` → **`평촌동 24-3`** (신탄진 공장과 별개 위치, 2.3km 거리)
격자는 68,102 로 동일해 조회 결과는 바뀌지 않습니다.
