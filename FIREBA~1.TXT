Firebase 보안규칙 — 아래 내용을 그대로 붙여넣으세요
────────────────────────────────────────────────
Firebase 콘솔 → Realtime Database → [규칙] 탭 → 전체 선택 후 붙여넣기 → [게시]

{
  "rules": {
    "days":      { ".read": true, ".write": true },
    "logs":      { ".read": true, ".write": true },
    "confirmed": { ".read": true, ".write": true },
    "autofix":   { ".read": true, ".write": true }
  }
}

────────────────────────────────────────────────
days      : 일자별 입력 내용
logs      : 변경 이력 (화면 표시 없음, 기록만)
confirmed : 폭염현황 확정 스냅샷 (수동 + 00시 자동)
autofix   : 00시 자동저장 중복 방지 표식

autofix 가 없으면 00시 자동저장이 여러 PC 에서 중복될 수 있습니다.
(기능 자체는 동작하며, 각 브라우저 기준으로 하루 한 번만 실행됩니다)

※ 이 규칙은 주소를 아는 사람 누구나 읽고 쓸 수 있는 상태입니다.
