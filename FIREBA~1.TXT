Firebase 보안규칙 — 아래 내용을 그대로 붙여넣으세요
────────────────────────────────────────────────
Firebase 콘솔 → Realtime Database → [규칙] 탭 → 전체 선택 후 붙여넣기 → [게시]

{
  "rules": {
    "days":      { ".read": true, ".write": true },
    "logs":      { ".read": true, ".write": true },
    "confirmed": { ".read": true, ".write": true }
  }
}

────────────────────────────────────────────────
days      : 일자별 입력 내용
logs      : 변경 이력 (화면 표시는 없고 기록만 남습니다)
confirmed : 폭염현황 확정 스냅샷

v3 에서는 사용자 관리·거점 관리를 없앴으므로 users / sites 규칙은 필요 없습니다.
(이미 넣어 두셨다면 그대로 둬도 무해합니다)

※ 이 규칙은 주소를 아는 사람 누구나 읽고 쓸 수 있는 상태입니다.
   더 잠그려면 Firebase 익명 인증을 켜고 ".write" 를 "auth != null" 로 바꾸세요.
