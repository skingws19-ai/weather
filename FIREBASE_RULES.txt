Firebase 보안규칙 — 아래 내용을 그대로 붙여넣으세요
────────────────────────────────────────────────
Firebase 콘솔 → Realtime Database → [규칙] 탭 → 전체 선택 후 붙여넣기 → [게시]

{
  "rules": {
    "days":  { ".read": true, ".write": true },
    "logs":  { ".read": true, ".write": true },
    "users": { ".read": true, ".write": true },
    "sites": { ".read": true, ".write": true }
  }
}

────────────────────────────────────────────────
이전에 안내드린 규칙에는 users / sites 가 빠져 있어
사용자 관리와 거점 관리가 401 Permission denied 로 막혔습니다.
위 규칙으로 교체하면 해결됩니다.

※ 이 규칙은 주소를 아는 사람 누구나 읽고 쓸 수 있는 상태입니다.
   사내 전용으로 쓰다가 더 잠그고 싶으면 Firebase 익명 인증을 켜고
   ".write" 를 "auth != null" 로 바꾸면 됩니다.
